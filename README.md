# AbheePay Payment Transaction Analysis | MIS Project

## Project Overview
The AbheePay Payment Transaction Analysis project focuses on monitoring and analyzing payment transaction data to generate meaningful MIS reports and business insights.

The project helps track payment performance, identify failed transactions, and monitor overall transaction success rates.

## Objectives
- Analyze total payment transactions.
- Identify successful and failed transactions.
- Calculate total successful transaction amounts.
- Measure transaction success percentage.
- Prepare reports for management decision-making.

## Key Performance Indicators (KPIs)
- Total Transactions
- Successful Transactions
- Failed Transactions
- Total Successful Amount
- Transaction Success Rate (%)

## Tools & Technologies
- Microsoft Excel
- Pivot Tables
- Excel Formulas
- Data Cleaning
- Data Validation
- Charts & Dashboard

## Business Insights
- Monitor payment transaction performance.
- Identify transaction failures.
- Track payment success rates.
- Support data-driven business decisions.
